# Real screenshots and clips

The site ships with illustrated screens. To use your own captures, add files here named after the
feature, then rebuild:

| File name (any of .png .jpg .webp .avif .mp4 .webm) | Feature |
|---|---|
| `library` | Local music library |
| `playback` | Music playback |
| `player` | Player design |
| `ai` | AI mixes |
| `auto` | Android Auto (shown in the car frame) |
| `video` | Video player (shown in a landscape phone) |
| `links` | Open links and streams |
| `hero` | The phone in the page header |

Portrait phone captures work best at about 1080 x 2340. Videos play muted and looped.
